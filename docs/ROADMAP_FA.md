# نقشه راه اسمارت‌مانی بات (فارسی)

> این سند زنده است — با هر نسخه به‌روز می‌شود. نسخه فعلی: `0.1.0` (موتور کامل + بک‌تست + پیپر-لایو + داشبورد).

## الان چی داریم (نسخه 0.1.0)

- هسته UT-Bot (کلاسیک + تطبیقی) روی تایم ۱۵ دقیقه، بدون ری‌پینت (سیگنال فقط با بسته شدن کندل)
- EMA200، ‏VWAP غلتان + VWAP لنگرشده به موج، SuperTrend، ‏ADX، ‏RSI
- مفاهیم اسمارت‌مانی: سقف/کف‌ها، BOS/CHoCH، اردربلاک با اعتبارسنجی دوگانه، FVG، زون‌های حمایت/مقاومت
- استک ۱۰ فیلتر ضد نویز + امتیاز اطمینان ۷ موتوره + رتبه‌بندی z-score
- حد ضرر ساختاری ضد استاپ‌هانت، ۴ تارگت R، سایز بر اساس ریسک، پیش‌بینی مدت معامله
- بک‌تست، پیپر-لایو (کراکن، بدون کلید)، آلارم تلگرام، داشبورد HTML

## فاز ۱ — استحکام (بعدی)

- [ ] ذخیره‌سازی نتایج در SQLite به‌جای JSON (تاریخچه سیگنال‌ها و معاملات)
- [ ] وب‌سوکت کراکن برای آپدیت زنده به‌جای polling
- [ ] تست بیشتر: بازار رنج بلندمدت، اسپایک خبری، قطعی اینترنت وسط پول
- [ ] حالت `--dry` برای چاپ سیگنال بدون ذخیره state

## فاز ۲ — هوش بیشتر

- [ ] تشخیص رنج/ترند در سطح مارکت (BTC.D، funding rate) برای خاموش‌کردن بات در chop

## فاز ۳ — محصول
