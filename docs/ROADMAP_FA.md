# نقشه راه اسمارت‌مانی بات (فارسی)

> این سند زنده است — با هر نسخه به‌روز می‌شود. نسخه فعلی: `0.2.0`.

## تازه‌ها در 0.2.0

- ‏`npm run tune` — گریدسرچ walk-forward-lite: انتخاب پارامتر روی نیمه اول تاریخچه + راستی‌آزمایی روی نیمه دوم
- خروجی CSV معاملات (`results/trades-*.csv`) برای اکسل + جمع‌بندی پرتفوی چندجفت‌ارزه (`results/portfolio.json`)
- مدیریت پوزیشن زنده: با لمس TP1 حد ضرر می‌آید سر‌به‌سر + آلارم تلگرام (کد خالص و تست‌شده در `src/positions.ts`)
- حالت `--dry` برای پیش‌نمایش سیگنال‌ها بدون ذخیره state و بدون پوزیشن
- تست‌های بیشتر (پوزیشن‌ها، تأییدیه ۲ کندله، cooldown) + ورک‌فلو CI روی گیت‌هاب (typecheck/test/build)

## الان چی داریم (نسخه 0.2.0)

- هسته UT-Bot (کلاسیک + تطبیقی) روی تایم ۱۵ دقیقه، بدون ری‌پینت (سیگنال فقط با بسته شدن کندل)
- EMA200، ‏VWAP غلتان + VWAP لنگرشده به موج، SuperTrend، ‏ADX، ‏RSI
- مفاهیم اسمارت‌مانی: سقف/کف‌ها، BOS/CHoCH، اردربلاک با اعتبارسنجی دوگانه، FVG، زون‌های حمایت/مقاومت
- استک ۱۰ فیلتر ضد نویز + امتیاز اطمینان ۷ موتوره + رتبه‌بندی z-score
- حد ضرر ساختاری ضد استاپ‌هانت، ۴ تارگت R، سایز بر اساس ریسک، پیش‌بینی مدت معامله
- بک‌تست، پیپر-لایو (کراکن، بدون کلید)، آلارم تلگرام، داشبورد HTML با نمودار کندل و زون‌ها
